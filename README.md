# اطلس سنگ‌های ساختمانی (Rock Atlas)

ساخته‌شده توسط **مهدی گیوکی** · تلفن: ‎+989192950266 · وب‌سایت: [www.nexstone.ir](https://www.nexstone.ir)

اپ اندرویدی آفلاین برای شناخت سنگ‌های ساختمانی ایران و جهان: گرانیت، مرمر، چینی و کریستال، مرمریت، تراورتن، مرمر سنگ (اونیکس)، سنگ آهک، ماسه‌سنگ، کوارتزیت، اسلیت، بازالت و سرپانتینیت.

## امکانات
- **اطلس با دسته و زیرمجموعه:** ۱۲ نوع سنگ و ۹۱ سنگ تجاری؛ هر نوع بر اساس رنگ به زیرمجموعه تقسیم می‌شود.
- **جستجو:** فارسی و انگلیسی، با نام تجاری، نام‌های دیگر، شهر، معدن و رنگ. «ي/ی» و «ك/ک»، نیم‌فاصله و ارقام فارسی یکسان در نظر گرفته می‌شوند. فیلتر بر اساس نوع، رنگ، کاربرد (کف، نما، کابینت، بک‌لایت…)، کشور و علاقه‌مندی‌ها.
- **منطقه و معدن:** هر سنگ مال کدام شهر و کشور است؛ صفحهٔ «مناطق» همه را بر اساس کشور و شهر نشان می‌دهد (ایران اول).
- **مشخصات آزمایشگاهی:** چگالی، جذب آب، مقاومت فشاری و خمشی، سختی موس، واکنش با اسید و استاندارد مرجع ASTM.
- **عکس:** از ویکی‌مدیا کامانز با پیوند پدیدآورنده و مجوز؛ پس از اولین بار روی گوشی ذخیره می‌شود.
- **شناسایی با عکس:** عکس با دوربین یا گالری، تطبیق رنگ و بافت به همراه آزمون‌های ساده (اسید، حفره، شفافیت، دانه، رگه) با بانک اطلاعاتی، کاملاً روی گوشی. دکمهٔ «پرسیدن از گوگل لنز» عکس را به اپ لنز می‌دهد (لنز API عمومی ندارد). با `tools/train_model.py` می‌توانید مدل هوش مصنوعی اختصاصی بسازید تا دقت بالا برود.

## امنیت
- فقط مجوز اینترنت؛ بدون مجوز دوربین، حافظه یا مکان (دوربین و گالری از طریق اپ‌های سیستم).
- فقط HTTPS، فقط گواهی‌های سیستمی، فقط دو دامنهٔ `en.wikipedia.org` و `upload.wikimedia.org`.
- حذف EXIF و مکان از عکس‌ها، محدودیت حجم و ابعاد تصویر ورودی، پاک‌سازی ورودی جستجو.
- `allowBackup=false`، FileProvider غیرصادراتی، فشرده‌سازی و مبهم‌سازی R8 در نسخهٔ release، بدون هیچ کلید یا رمز در کد (امضای release از متغیرهای محیطی خوانده می‌شود).

## ساخت APK

### روش ۱: GitHub (بدون نصب چیزی)
1. یک مخزن خصوصی در GitHub بسازید و همهٔ این پوشه را در آن push کنید.
2. در تب **Actions** گردش‌کار «Build APK» خودکار اجرا می‌شود.
3. پس از پایان، فایل `rock-atlas-debug-apk` را از بخش Artifacts دانلود و روی گوشی نصب کنید.

### روش ۲: Android Studio
پوشه را در Android Studio (نسخهٔ Ladybug یا جدیدتر) باز کنید و Run را بزنید، یا:
```
./gradlew assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### نسخهٔ release امضاشده
```
export ROCKATLAS_KEYSTORE=/path/to/release.jks
export ROCKATLAS_KEYSTORE_PASSWORD=...
export ROCKATLAS_KEY_ALIAS=...
export ROCKATLAS_KEY_PASSWORD=...
./gradlew assembleRelease
```

## افزودن یا ویرایش سنگ‌ها
داده‌ها در `tools/build_seed.py` هستند. سطر جدید اضافه کنید، `SEED_VERSION` را یکی بالا ببرید و اجرا کنید:
```
python3 tools/build_seed.py
```
فایل `app/src/main/assets/seed.json` دوباره ساخته می‌شود و اپ نصب‌شده در اجرای بعد آن را وارد می‌کند (علاقه‌مندی‌ها و عکس‌های ذخیره‌شده حفظ می‌شوند).

> مقادیر آزمایشگاهی محدودهٔ معمول هر نوع سنگ است، نه نتیجهٔ آزمایش یک معدن خاص. مناطق معادن از منابع عمومی گردآوری شده‌اند و پیش از استفادهٔ تجاری باید صحت‌سنجی شوند.
